# Advanced — CLI and API

This is the developer and automation companion to [Quick start](/docs/ai-studio/quick-start). It covers running AI Studio's agent from a terminal (`robonito-cli`) and driving it through the app-server API.

---

## The CLI (`robonito-cli`)

The CLI runs the **same** web-testing agent as the desktop app, from a terminal. CLI v1 supports the **web** platform only.

### Prerequisites

- Node.js 20 or newer.
- The Robonito monorepo and its local packages built.
- A running Robonito app server, and access to at least one organization and workspace.
- Chromium from Playwright (or a compatible Chromium executable).
- Ollama only when using an Ollama model.

The CLI deliberately fails when the configured Robonito server is unavailable.

### Install and build

From the monorepo root, build the local packages the CLI requires, then:

```bash
cd cli-agent
npm install
npm run build
```

Run via `npm run dev --` (TypeScript) or `npm start --` (compiled). The examples below use `npm run dev --`.

### First login

```bash
npm run dev -- auth login
```

This opens the system browser for authentication. On success it:

1. Stores the refresh session in the operating-system credential vault.
2. Asks you to select an authorized organization and workspace when needed.
3. Offers an authorized model selection.
4. Asks for testing mode and diagnostics preferences.
5. Starts the interactive Robonito terminal at the `robonito>` prompt.

### Common runs

```bash
# Interactive session, then type a request at robonito>
npm run dev

# One-shot run, then exit
npm run dev -- run "Test login on https://www.saucedemo.com with standard_user"

# Plan or Explore mode
npm run dev -- run "Plan coverage for https://example.com" --planning
npm run dev -- run "Explore https://example.com and identify critical journeys" --explore

# Attach one or more files
npm run dev -- run "Use these requirements to test the site" --attach ./requirements.txt

# A persona (core personas need no --personas-dir)
robonito-cli --persona sales-rep -w <workspaceId> \
    --instructions "Create an opportunity for Acme, $50k, Prospecting stage"
```

### Options

| Option | Purpose | Default |
|---|---|---|
| `-i, --instructions S` | One-shot instructions (`-` reads stdin). | Interactive. |
| `--attach PATH` | Attach a file (repeatable). | None. |
| `-p, --provider TYPE` | `robonito`, `anthropic`, `openai`, `google`, or `ollama`. | `robonito`. |
| `-m, --model NAME` | Model id. | `robonito-default`. |
| `--choose-model` | Force selection from the authorized catalog. | Off. |
| `-pl, --platform TYPE` | Requested platform (v1: `web` only). | `web`. |
| `-w, --workspace-id` / `--organization-id` | Override saved context. | Saved. |
| `-t, --thread-id` | Use a specific thread. | New. |
| `--headed` | Show the browser. | On for interactive non-benchmark. |
| `--executable-path PATH` | Specific Chromium executable. | Playwright Chromium. |
| `--planning` / `--explore` | Enable Plan / Explore mode. | Off. |
| `--non-interactive` | Disable HITL; auto-reject requests. | Off. |
| `--hitl-timeout-ms MS` | Max wait for a HITL response (milliseconds). | `600000`. |
| `-v, --verbose` | Verbose activity + diagnostic logs. | Off. |
| `--output FORMAT` | Human terminal output or `jsonl` JSON Lines. | `human`. |
| `--json-summary PATH` | Write the run summary as JSON. | None. |
| `--evidence PATH` | Write a redacted evidence pack. | None. |

<Note type="danger" title="Don't commit tokens">
For automation, authenticate once and pass a short-lived `ROBONITO_AUTH_TOKEN` through the environment. Never write a token to a committed `.env` file.
</Note>

### Environment

A `.env` file in `cli-agent` is loaded automatically. Browser login usually removes the need for credentials or IDs in it.

| Variable | Default | Purpose |
|---|---|---|
| `ROBONITO_SERVER_URL` | `http://localhost:3000/app-server` | App-server base URL. |
| `ROBONITO_CLOUD_GATEWAY_URL` | `http://localhost:3001` | Cloud execution gateway. |
| `ROBONITO_API_GATEWAY_URL` | `http://localhost:3002` | API execution gateway. |
| `ROBONITO_CONFIG_DIR` | `~/.robonito` | Saved context directory. |
| `ROBONITO_AUTH_TOKEN` | — | Short-lived access-token override (for automation). |
| `ROBONITO_ORGANIZATION_ID` / `ROBONITO_WORKSPACE_ID` | Saved | Context override. |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Local Ollama proxy URL. |
| `LANGSMITH_API_KEY` | None | Required to enable `--langsmith` tracing. |

### Exit codes

| Code | Meaning |
|---|---|
| `0` | Success. |
| `1` | Startup/configuration or unhandled failure. |
| `2` | Agent/test failure. |
| `3` | Authentication failure. |
| `4` | HITL required or failed. |
| `5` | Run budget exhausted. |
| `130` | Cancelled / interrupted. |

`Ctrl+C` cancels the active run and disposes browser/session resources.

### Troubleshooting

- **`auth_required`** — run `npm run dev -- auth login`; for machines, also pass a complete org/workspace pair or save one with `context use`.
- **Browser login won't return** — the CLI uses a loopback callback, with a manual paste fallback. Ensure the app-server CLI auth endpoints and Firebase web configuration are available.
- **Context selection fails** — confirm you're a member of the requested org/workspace; explicit IDs are revalidated, arbitrary ones aren't accepted.
- **Server/gateway connection fails** — check the three Robonito URLs and that the app server plus the required execution gateway are running.
- **Chromium won't launch** — `npx playwright install chromium`, or pass `--executable-path /path/to/chromium`.
- **Run finishes but test persistence fails** — standard authoring runs need a durable persisted artifact; planning, explore, and benchmark runs don't. Inspect the JSON summary or evidence pack for the persistence status.
- **Playwright binaries** — must match the version matrix in the [Installation](/docs/installation) guide.

## App-server API

The desktop app and a server/CLI client reach AI Studio through a backend controller at the prefix **`ai-studio`**. All routes require authentication and a workspace guard. Default base URL: `http://localhost:3000/app-server`.

| Method & path | Purpose |
|---|---|
| `POST /ai-studio/threads` | Create a thread. |
| `GET /ai-studio/threads` | List threads. |
| `POST /ai-studio/threads/:id/messages` | Send a message / start a run. |
| `GET /ai-studio/threads/:id/messages` | List a thread's messages (paginated: default 100, max 250). |
| `PATCH /ai-studio/threads/:id/bind-suite` | Bind a thread to its suite (write-once). |
| `POST /ai-studio/test-cases/enqueue` | Enqueue test-case persistence (async). |
| `GET /ai-studio/test-cases/persistence/:jobId` | Poll an async persistence job. |
| bug-ledger routes | Create / list / resolve recorded bugs. |

Run terminal states: `succeeded` · `failed` · `cancelled` · `human_intervention_required` · `budget_exhausted` · `infrastructure_failed`.
